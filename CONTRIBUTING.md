# Contributing to Scout

Scout is not currently accepting outside code contributions.

You may report issues and discuss ideas, but do not submit source-code patches
or pull requests for incorporation yet. The project intends to establish a
future legal entity and contributor agreement before accepting external code.
That agreement must preserve the project's ability to maintain the public
source licenses and, if later offered, separate commercial licenses.

An unsolicited submission is not accepted merely because it was posted to an
issue, pull request, discussion, email, or other project channel. Scout's
maintainers will not merge outside code until the contributor agreement is in
place and has been accepted by the contributor.

Documentation-only suggestions may be discussed, but any copyrightable text
will be handled under the same contribution process unless the maintainers
state otherwise in writing.
